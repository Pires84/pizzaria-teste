# Modelo profissional para sites de negócios locais

Para cada novo cliente:
1. Duplique esta pasta.
2. Renomeie a cópia com o nome do cliente.
3. Preencha `BRIEFING-CLIENTE.md`.
4. Defina a identidade em `DESIGN-SYSTEM.md`.
5. Consulte `AGENTS.md`.
6. Use `CHECKLIST-ENTREGA.md` antes de publicar.

Regra principal: o processo é padronizado, mas o site final não deve parecer um template.
