# Checklist antes da entrega

## Estratégia
- [ ] Objetivo principal claro?
- [ ] Conversão principal definida?
- [ ] Proposta de valor clara?
- [ ] Conteúdo responde às principais dúvidas?

## Mobile
- [ ] Sem rolagem horizontal?
- [ ] Textos legíveis?
- [ ] Botões fáceis de tocar?
- [ ] CTA aparece cedo?
- [ ] Menu funciona?

## Funcional
- [ ] WhatsApp funciona?
- [ ] Telefone funciona?
- [ ] E-mail funciona?
- [ ] Formulários funcionam?
- [ ] Links internos funcionam?
- [ ] Mapa funciona?

## Conteúdo
- [ ] Nenhum dado inventado?
- [ ] Sem lorem ipsum?
- [ ] Endereço correto?
- [ ] Telefone correto?
- [ ] Horário correto?
- [ ] Preços corretos?
- [ ] Ortografia revisada?

## Acessibilidade
- [ ] H1 único?
- [ ] Headings organizados?
- [ ] Foco visível?
- [ ] Imagens relevantes com alt?
- [ ] Contraste adequado?

## SEO básico
- [ ] Title?
- [ ] Meta description?
- [ ] Cidade/bairro em contexto natural?
- [ ] Serviço principal no conteúdo?
- [ ] Nome, endereço e telefone consistentes?

## Performance
- [ ] Imagens otimizadas?
- [ ] Sem scripts desnecessários?
- [ ] Site abre rapidamente no celular?

## Publicação
- [ ] Build sem erros?
- [ ] Git atualizado?
- [ ] GitHub atualizado?
- [ ] Site público testado?
- [ ] Site testado no celular real?
