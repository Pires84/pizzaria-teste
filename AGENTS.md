# Regras permanentes para IA e desenvolvimento

Antes de criar ou alterar o site, consultar:
1. BRIEFING-CLIENTE.md
2. DESIGN-SYSTEM.md
3. CHECKLIST-ENTREGA.md

## Prioridades
1. Clareza
2. Conversão
3. Experiência mobile
4. Confiança
5. Identidade visual
6. Acessibilidade
7. Performance
8. Manutenção simples

## UX
O visitante precisa entender rapidamente:
- o que a empresa oferece;
- para quem é;
- onde atende;
- por que confiar;
- como agir agora.

## UI
O visual deve nascer do negócio.
Evitar aparência genérica de template, excesso de cards, animações desnecessárias e repetir o mesmo design em clientes diferentes.

## Conteúdo
Nunca inventar endereço, telefone, preços, avaliações, anos de experiência, certificações, garantias ou resultados.
Se faltar informação, usar placeholder identificado.

## Código
Priorizar HTML semântico, CSS organizado, JavaScript simples, poucas dependências, responsividade e acessibilidade.

## Mobile first
Sem rolagem horizontal, botões fáceis de tocar, CTA cedo, texto legível, imagens responsivas e navegação simples.

## Performance
Evitar imagens pesadas, vídeos automáticos, scripts e bibliotecas desnecessárias.

## Antes de concluir
Testar desktop, celular, links, WhatsApp, telefone, formulários, navegação, ortografia, acessibilidade, dados e performance.
