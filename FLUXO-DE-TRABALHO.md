# Fluxo padrão

1. Descoberta — preencher briefing.
2. Estratégia — público, objetivo, CTA, objeções, provas e estrutura.
3. UX — ordem das informações e jornada.
4. UI — direção visual específica.
5. Conteúdo — hero, serviços, diferenciais, prova, FAQ e CTA.
6. Desenvolvimento — site responsivo.
7. QA — usar `CHECKLIST-ENTREGA.md`.
8. Git — criar commit.
9. Publicação — publicar e testar no celular.
10. Entrega — URL, acessos, orientações e manutenção.
